# 🚀 Smart Job & Internship Tracker

An intuitive and feature-rich application designed to help students and job seekers streamline their job search journey. Keep track of your applications, interview schedules, deadlines, and follow-ups all in one centralized dashboard.

---

## ✨ Features

* **📊 Centralized Dashboard:** View all your active, pending, rejected, and accepted applications at a glance.
* **🔄 Status Tracking:** Easily update stages (Applied, Interviewing, Offered, Rejected).
* **⏰ Deadlines & Reminders:** Never miss an interview or assessment deadline.
* **🔗 Quick Links:** Save direct links to job descriptions, company portals, and your customized resumes.
* **⚡ Modern Tech Stack:** Built with a clean UI and a robust backend for seamless performance.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite) / Tailwind CSS *(Update as per your stack)*
* **Backend:** Python (Flask) / REST APIs *(Update as per your stack)*
* **Database:** SQLite / PostgreSQL *(Update as per your stack)*

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine:

### Prerequisites
* Node.js & npm installed
* Python installed

### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/your-username/smart-job-tracker.git
cd smart-job-tracker
\`\`\`

### 2. Backend Setup
\`\`\`bash
cd backend
# Create virtual environment & install dependencies
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
pip install -r requirements.txt
python app.py
\`\`\`

### 3. Frontend Setup
\`\`\`bash
cd frontend
npm install
npm run dev
\`\`\`
